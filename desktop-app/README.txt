SMART DJ TRANSITION FINDER - WERSJA BEZ INSTALACJI

1. Kliknij dwa razy SmartDJTransitionFinder.html
   albo URUCHOM-SMART-DJ.cmd.

2. Wpisz tytul lub fragment tytulu.

3. Przelacznik:
   - Playlist Match: dopasowania z Twojej playlisty
   - Whole: dodatkowy katalog utworow w podobnym klimacie

4. Twoje recznie dodane utwory zapisuja sie w przegladarce.
   Przyciski Eksport bazy / Import bazy pozwalaja zrobic kopie.

Aplikacja dziala offline i nie wymaga Node.js, serwera ani instalacji.
